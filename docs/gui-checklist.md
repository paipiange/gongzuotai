# 拍片哥工作台 · GUI 点验清单

> 用法：在真实 DeepSeek Harness 桌面实例上，按顺序逐项操作并勾选。每一项都给出
> 「操作步骤 → 预期结果」，通过即勾 `[x]`。
>
> 前置：已完成 `pnpm build:plugin` + `bash scripts/sync.sh` 并重启 dsh；侧边栏已出现
> 「拍片哥工作台」入口。本文只覆盖**需要手动点验**的项，纯代码/单测已覆盖的项不在内。

---

## 0. 启动与健康检查

- [ ] 打开 dsh，点击侧边栏「拍片哥工作台」，主界面正常渲染、无白屏。
- [ ] 打开 DevTools（dsh 开发者工具），Console 无红色未捕获异常、无 `import()` 动态加载失败。

---

## 1. 文本生成（流式逐字渲染）

**入口**：侧边栏「AI 创作」→ 选择「AI 文章生成」（或 爆款标题 / 营销文案 / 小红书笔记）。

- [ ] 工作室页填写「主题」，点「开始生成」。
- [ ] 预期：正文在 Markdown 编辑器里**逐字流式**填入（不是一次性蹦出）。
- [ ] 预期：生成中按钮变「停止生成」，可中途点它取消。
- [ ] 预期：完成弹出 toast「生成完成，内容已填入画布」，内容随草稿自动保存。
- [ ] 预期：切到「创作记录 → 生成记录」，能看到这次文本任务的请求参数与日志。

---

## 2. 生图（图片直接带文字，中文渲染质量）

**入口 A（独立生图）**：首页或「AI 创作」→「AI 图片生成」。
**入口 B（公众号竖图）**：侧边栏「公众号创作」→ 拆页后逐页生图。

- [ ] 在 prompt 里要求「图片内直接渲染中文标题」，点「开始生成」。
- [ ] 预期：出图里中文**无乱码、无错字、无明显笔画粘连**，文字清晰。
- [ ] 预期：公众号竖图输出为**竖版**（约 4:5，如 1024×1280），不是方图。
- [ ] 预期：多张参考图（粘贴到输入框）生图时，参考元素融合自然。

---

## 3. 公众号创作完整链路 + 恢复链路（重点）

**入口**：侧边栏「公众号创作」。

### 3.1 主流程
- [ ] 素材框粘贴一段含金额/事实的文本（可再粘贴 1~2 张参考图），点「AI 拆页」。
- [ ] 预期：拆出多页分镜（页卡显示 page_type / 标题 / 副标题）。
- [ ] 预期：每页点「生成此页底图」能出带文字的竖图；或点「批量生图（跳过已生成）」一次出多页。
- [ ] 预期：批量生图是**并发**进行（多页同时转圈），不是一页一页串行等。

### 3.2 离开再返回（后端任务恢复）
- [ ] 拆页后**不要等生图完成**，直接切到别的页面（如首页），再切回「公众号创作」。
- [ ] 预期：素材文本、拆页结果、已生成的图片**原样恢复**。
- [ ] 预期：正在进行中的页显示「生成中…」，后台跑完后**自动出图**回填。
- [ ] 预期：进行中页切走期间，生图任务在后台完成并落盘，回来能对上。
- [ ] 预期：完全退出 dsh 再重开，进入公众号创作仍能恢复上次会话。

---

## 4. 创作记录（归档 / 恢复 / 永久删除）

**入口**：侧边栏「创作记录」。

- [ ] 对一条记录点「归档」，状态变为「已归档」。
- [ ] 切到「已归档」筛选，点卡片上的「恢复」图标，记录回到「进行中」，状态变草稿。
- [ ] 勾选多条 → 「批量归档」/「批量恢复」生效。
- [ ] 点「删除」（垃圾桶）→ 确认框 → 记录被软删（进回收站概念，不立即物理删除）。
- [ ] 勾选多条 → 「批量删除」→ 确认后全部删除。
- [ ] 预期：以上操作重启 dsh 后**状态持久**（走 Host SQLite，非浏览器本地缓存）。

---

## 5. 素材库（上传 + 存储清理）

**入口**：侧边栏「素材库」。

- [ ] 点「导入素材」，选一张图片 / 一个文本文件，成功后出现在素材库列表。
- [ ] 预期：图片能正常预览（缩略图可见）。
- [ ] 删除一张素材 → 进入回收站；点「存储清理」弹窗里能看到「回收站（已删除素材）」数量与体积。
- [ ] 点「清空回收站」→ 确认 → 提示释放字节数，回收站计数归零。
- [ ] 有孤儿图片时（生图未引用即离开场景），弹窗「孤儿图片」项显示数量，点「清理孤儿图片」后归零。
- [ ] 预期：清理后磁盘上对应 `.png` 文件真的被删除（可去 `~/.dsh/paipiange/media/images/` 抽查文件数减少）。

**入口**：侧边栏底部「模型与设置」或「设置中心」。

- [ ] 「文本模型」下拉能看到 `huatu717333` / `aaa42w` 等可用 provider，模型可从 catalog 选择。
- [ ] 「后端管理」能新增/编辑/删除图片后端（llm-image / comfyui），「测试连接」返回可达性。

- [ ] 预期：重启 dsh 后后端配置仍存在。

## 7. 生成记录（任务日志 + 继续修改）

**入口**：侧边栏「创作记录」→「生成记录」tab。

- [ ] 文字、图片任务各留一条记录，能看到请求参数（脱敏）与返回日志。
- [ ] 对一条记录点「继续修改」/恢复入口，能回到对应创作并继续编辑。

## 8. 卸载与热重载

- [ ] 在 dsh 插件管理中禁用/卸载「拍片哥工作台」插件。
- [ ] 预期：插件卸载时 `webServer` 路由 disposer 全部调用，无残留路由、无报错；侧边栏入口消失。
- [ ] 预期：重新启用插件后，无重复面板、无重复侧边栏入口。
